Welcome! You actually found this hidden place!
This is a special branch of **JYACS**, mainly documenting the development process of the JYACS frontend. Here you can find the very first prototype version of JYACS, ~~although versions before beta12 might throw errors on startup~~.
As a developer, you can try downloading different versions, comparing the different errors to help you learn Ren'Py and debug errors.
Note: All version numbers in this branch are independent of the main branch, and the different beta versions are named just for better distinction.
If you have any questions, feel free to reach out to me!
